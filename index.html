01
Kéo thả & Tùy chỉnh tên

Tải file .litematic của bạn lên, sau đó nhập tên mong muốn cho Addon rồi nhấn tải về.

02
Tải & Mở file .mcpack

Mở file .mcpack vừa tải, Minecraft Bedrock sẽ tự động import vào game.

03
Kích hoạt trong World

Vào cài đặt World rồi vào Behavior Pack sau đó thêm cái file vừa tải vào. Sau đó bật Beta APIs trong phần Thử nghiệm (Experiments).

04
Cách sử dụng

Cầm Stick, Feather hoặc Compass nhấp chuột phải(đè/giữ vào màn hình điện thoại) để mở menu, chọn TP Mode để bắt đầu, lưu ý là hãy bay lên 1 khoản và không di chuyển đến khi nó chạy xong.
