HƯỚNG DẪN SỬ DỤNG MCPE / BEDROCK
01
Kéo thả & Tùy chỉnh tên

Tải file .litematic của bạn lên, sau đó nhập tên mong muốn cho Addon rồi nhấn tải về.

02
Tải & Mở file .mcaddon

Mở file .mcaddon vừa tải, Minecraft Bedrock sẽ tự động import vào game (hoặc giải nén thư mục _bp vào thư mục game).

03
Kích hoạt trong World

Vào cài đặt World rồi vào Behavior Pack sau đó thêm file vừa tải vào. Sau đó bật Beta APIs trong phần Thử nghiệm (Experiments).

04
Cách sử dụng & Lưu ý quan trọng

Cầm Stick, Feather hoặc Compass nhấp chuột phải (đè/giữ vào màn hình điện thoại) để mở menu, chọn TP Mode để bắt đầu.

⚠️ Lưu ý: Hãy đứng im cho đến khi load xong đừng di chuyển, tốc độ xử lý và load schematic tùy thuộc vào cấu hình máy.
